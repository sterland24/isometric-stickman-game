# Isometric Minimal Stickman Game 🏃‍♂️🌿

A lightweight, minimal isometric stickman game built with vanilla HTML5 Canvas and JavaScript.

✨ **Crafted with Artificial Intelligence**

## Features
- **Minimalist Aesthetic:** Clean, white-canvas design with natural hand-drawn-style isometric foliage.
- **Isometric Projection:** True 2:1 isometric coordinates and perspective with smooth dynamic depth sorting.
- **Fluid Stickman Animation:** Stickman character with physics, smooth movement, and directional leg stride cycles.
- **Mobile & Touch Support:** Full touch and pointer support with tap-to-move, drag-to-steer, dynamic ripple effects, and adaptive UI.
- **Controls:**
  - Movement: `W`, `A`, `S`, `D`, Arrow keys (`←`, `↑`, `↓`, `→`), or Tap / Drag mouse or touch
  - Run/Sprint: Hold `Shift` or drag further away from stickman

## How to Play
Simply open `index.html` in any modern web browser or host via GitHub Pages.
